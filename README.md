# IM.CON WordPress Image Converter Plugin

## Description
A lightweight WordPress plugin that lets site administrators convert images (JPG, PNG, WEBP, AVIF) via a drag‑&‑drop admin UI. After conversion the plugin stores the image in the Media Library, shows a preview, and generates a shortcode that can be embedded on any post or page.

## Features
- **Drag‑&‑drop / file‑selector** UI in a custom admin dashboard.
- Automatic conversion (placeholder – uses the original image for now, can be extended with GD/Imagick).
- Preview of the uploaded image immediately after conversion.
- Generated shortcode `[im_con_image id="{attachment_id}"]` ready to copy.
- Settings page for default conversion quality.
- System‑Status page showing GD/Imagick availability and upload directory writability.
- Shortcode support with optional size and custom CSS class.

## Installation
1. Copy the entire `im-con-plugin` folder into `wp-content/plugins/` on your WordPress site.
2. In the WordPress admin, go to **Plugins → Installed Plugins** and click **Activate**.
3. The activation hook flushes rewrite rules automatically.
4. Navigate to **IM.CON → Dashboard** to start converting images.

## Shortcode Usage
Insert the shortcode generated by the dashboard (or manually) into any post or page:

```php
[im_con_image id="123"]
```

Optional attributes:
- `size` – WordPress image size slug (`thumbnail`, `medium`, `large`, etc.). Default: `large`.
- `class` – Custom CSS class for the `<img>` tag. Default: `im-con-output`.

Example:
```php
[im_con_image id="123" size="medium" class="my‑custom‑class"]
```

## Requirements
- WordPress 5.0 or later.
- PHP 7.4+ with the **GD** library or **Imagick** extension installed (at least one is required for conversion).
- Write permissions on the `wp‑uploads` directory.
- No external dependencies; all assets are bundled in the plugin.

## Development & Extending
- Conversion logic can be expanded in `includes/class-im-con-engine.php` (currently a placeholder).
- UI styles are in `admin/css/im-con-admin.css`; feel free to customize.
- JavaScript is in `admin/js/im-con-admin.js` using jQuery and WordPress media scripts.
